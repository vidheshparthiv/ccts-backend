Request Mapping
- @getMapping --- GET --- fetch data --- select query
- @postMapping -- POST -- Insert data --- insert query
- @putMapping --- PUT --- update data based on id --- update query
- @deleteMapping -- DELETE -- delete data based on id -- delete query
- @requestMapping -- ANY -- Base url

Types of Entity mapping:

1.One to One
2.One to Many
3.Many to Many
4.Many to Many

ONE_TO_ONE: (@Onetoone)
- one record in table A is related to exactly one record in B if A is not there, then there will be no existance of table B
- one Entity cannot exists without other
- relation is unique
- @JoinColumn() - create foreign key
eg : student ----- Attendence
     Person ---- IDProof

ONE_TO_MANY(@Onetomany())
- one record is table A is related to many record in table B
- @onetomany(cascade=Cascadetpe.____)//controls what happends to the child entity
 -- Any operation done on the parent is automatically applied to its child entities.
 -- Parent controls the children.
	1.ALL - all operations
	2.Persist - save
	3.Remove - delete
	4.Merge - update
eg : one teacher ----- many students

MANY_TO_ONE
